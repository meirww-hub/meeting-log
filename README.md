# Meeting Log - הקלטה, תמלול, סיכום ו-TO DO אוטומטי

מערכת שמקליטה שיחות דרך אפליקציית אנדרואיד, מתמללת אותן לזרם טקסט שטוח
(בלי זיהוי דוברים), מפיקה סיכום ורשימת משימות (עם גאנט לאבני דרך אם יש
תאריכים), ושומרת הכול בגוגל דרייב - תיקייה לכל סוג תוצר ("סיכום", "תמלול",
"TO DO", "הקלטות", "הערות", "קבצים מצורפים"), וכל קובץ בתוכה נושא את הסוג
ואת כותרת הפגישה ("סיכום - ישיבת צוות").

התוכנית המלאה: `docs/plan.md` (עותק של תוכנית האישור המקורית).

## מבנה הפרויקט

```
backend/    שרת עיבוד Python (FastAPI, מיועד ל-Cloud Run)
android/    אפליקציית אנדרואיד (Kotlin) - הקלטה, היסטוריה, צ'אט
docs/       תיעוד נוסף
```

## דרישות הקמה לפני הרצה

1. **פרויקט Google Cloud** חדש, עם הפעלת:
   - Google Drive API
   - Google Sheets API (נדרש לבניית גיליון ה-TO DO + טאב הגאנט)
   - Firestore (Native mode)
   - (אופציונלי) Google Calendar API
2. **מפתח Gemini API** (Google AI Studio, יש שכבה חינמית) - לתמלול
   וגם לסיכום וחילוץ משימות (הכל דרך אותו מפתח).
3. **OAuth Client ID** (Android + Web) ל-Google Sign-In מול Drive/Calendar.
4. קובץ `backend/.env` (ראו `backend/.env.example`) עם המפתחות/הגדרות.

## הרצת הבקאנד מקומית

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## פתיחת אפליקציית האנדרואיד

1. פתחו את תיקיית `android/` בתור פרויקט ב-Android Studio (הוא ישלים
   אוטומטית את ה-Gradle wrapper וקבצים חסרים כמו אייקון האפליקציה).
2. עדכנו את `BACKEND_BASE_URL` בקובץ `android/app/build.gradle.kts`
   לכתובת שרת העיבוד האמיתית (למשל כתובת Cloud Run) לפני build.
3. הריצו על מכשיר/אמולטור אנדרואיד עם הרשאת מיקרופון.

## שלט הקלטה בשעון (Wear OS)

מודול `android/wear/` הוא אפליקציית Wear OS שרק מתחילה ועוצרת את ההקלטה
**בטלפון** (השעון לא מקליט בעצמו, ואין בו מיקרופון פעיל). עובד על כל שעון
Wear OS 3+ (Galaxy Watch, Pixel Watch, TicWatch...) - הוא משתמש רק ב-Data Layer
של Google, בלי ערכות פיתוח של יצרן מסוים. הפרוטוקול נמצא ב-
`android/shared/watch/WatchProtocol.kt` ומשותף לשני המודולים.

איך זה עובד: לחיצה בשעון שולחת "התחל" לטלפון. מאנדרואיד 14 אפליקציה ברקע לא
יכולה לפתוח מיקרופון, ולכן הטלפון מעלה לשנייה מסך שקוף
(`WatchStartActivity`, גם מעל מסך נעילה) ומתוכו מתחיל את `RecordingService`
כמו כפתור ההקלטה. זה דורש הרשאת "הצגה מעל אפליקציות אחרות". השעון מציג
"מקליט" ורוטט רק אחרי שהטלפון אישר שההקלטה באמת רצה. עצירה מהשעון שומרת את
ההקלטה על הדיסק וממתינה ל"שלח לעיבוד" בטלפון, בדיוק כמו עצירה מהכפתור באפליקציה.

בנייה והתקנה (JAVA_HOME = ה-JBR של Android Studio):

```
gradlew :app:assembleDebug :wear:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb connect <כתובת השעון>:<פורט>
adb -s <כתובת השעון>:<פורט> install -r wear/build/outputs/apk/debug/wear-debug.apk
```

שתי האפליקציות חייבות להיות עם אותו package ואותה חתימה (ה-Data Layer מחבר רק
ביניהן) - לכן בונים את שתיהן מאותו מחשב.

## סטטוס

ל-Drive.

ביום היעד, באותו צבע כמו השורה שלה בטאב "משימות"; דחיפת אבני דרך ל-Google
Calendar (הסעיף האופציונלי בשלב 3) עדיין לא מומשה.
עדיין נדרש: חיבור מפתחות/חשבונות אמיתיים (ראו "דרישות הקמה" למעלה), בדיקת
קצה-לקצה מול הקלטה אמיתית, ולאחר מכן שלב 4 בתוכנית (`docs/plan.md`): ליטוש.
