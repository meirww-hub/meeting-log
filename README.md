# Meeting Log - הקלטה, תמלול, סיכום ו-TO DO אוטומטי

מערכת שמקליטה שיחות דרך אפליקציית אנדרואיד, מתמללת אותן תוך זיהוי דוברים
לפי קול, מפיקה סיכום ורשימת משימות (עם גאנט לאבני דרך אם יש תאריכים),
ושומרת הכול בגוגל דרייב - תיקייה לכל סוג תוצר ("סיכום", "תמלול", "TO DO",
"הקלטות", "הערות", "קבצים מצורפים"), וכל קובץ בתוכה נושא את הסוג ואת כותרת
הפגישה ("סיכום - ישיבת צוות").

התוכנית המלאה: `docs/plan.md` (עותק של תוכנית האישור המקורית).

## מבנה הפרויקט

```
backend/    שרת עיבוד Python (FastAPI, מיועד ל-Cloud Run)
android/    אפליקציית אנדרואיד (Kotlin) - הקלטה, תיוג דוברים, היסטוריה
docs/       תיעוד נוסף
```

## דרישות הקמה לפני הרצה

1. **פרויקט Google Cloud** חדש, עם הפעלת:
   - Google Drive API
   - Google Sheets API (נדרש לבניית גיליון ה-TO DO + טאב הגאנט)
   - Firestore (Native mode)
   - (אופציונלי) Google Calendar API
2. **מפתח Gemini API** (Google AI Studio, יש שכבה חינמית) - לתמלול+diarization
   וגם לסיכום וחילוץ משימות (הכל דרך אותו מפתח).
3. **OAuth Client ID** (Android + Web) ל-Google Sign-In מול Drive/Calendar.
4. קובץ `backend/.env` (ראו `backend/.env.example`) עם המפתחות/הגדרות.

## הרצת הבקאנד מקומית

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## פתיחת אפליקציית האנדרואיד

1. פתחו את תיקיית `android/` בתור פרויקט ב-Android Studio (הוא ישלים
   אוטומטית את ה-Gradle wrapper וקבצים חסרים כמו אייקון האפליקציה).
2. עדכנו את `BACKEND_BASE_URL` בקובץ `android/app/build.gradle.kts`
   לכתובת שרת העיבוד האמיתית (למשל כתובת Cloud Run) לפני build.
3. הריצו על מכשיר/אמולטור אנדרואיד עם הרשאת מיקרופון.

## סטטוס

שלד קוד לשלב 1 (MVP) קיים: אפליקציית אנדרואיד להקלטה והעלאה, ושרת עיבוד
עם תמלול + diarization בסיסי + סיכום/TO DO דרך Gemini + כתיבה ל-Drive.
שלב 3 (גאנט) מומש חלקית: גיליון ה-TO DO כולל טאב "גאנט" חזותי - כל משימה
עם תאריך יעד מקבלת פס צבעוני (מתאריך הפגישה ועד תאריך היעד) וסימון אבן-דרך
ביום היעד, באותו צבע כמו השורה שלה בטאב "משימות"; דחיפת אבני דרך ל-Google
Calendar (הסעיף האופציונלי בשלב 3) עדיין לא מומשה.
עדיין נדרש: חיבור מפתחות/חשבונות אמיתיים (ראו "דרישות הקמה" למעלה), בדיקת
קצה-לקצה מול הקלטה אמיתית, ולאחר מכן שלב 2 בתוכנית (`docs/plan.md`): זיהוי
דוברים לומד, ושלב 4: ליטוש.
